# 我创造的完美球员（NBA Perfect Player）

一个纯前端 H5 生涯模拟游戏：从现代或历史名单中“夺取属性”，打造属于自己的传奇球星，完整经历新秀、巅峰、老将与退役。

## ✨ 功能特性

- **建球员老虎机**：从球队随机抽取球员，夺取 13 项属性；跨位置衰减可开关；随机选队不重复
- **历史时代开局**：1984（乔丹、奥拉朱旺）、1996（黄金一代）、2003（白金一代）三档历史名单，联盟规模按真实年份演化（24 → 29 → 30 队）
- **完整生涯循环**：新秀 → 巅峰 → 老将 → 退役特刊 / 生涯海报，历史档位评定（GOAT / 历史前十 / 百大）
- **真实数据驱动**：工资帽按 1984-2027 真实轨迹逐年校准，球员合同/薪水随时代演化，历史冠军与 FMVP 锚点
- **事件系统**：常规赛/季后赛事件、NBA 名场面、关键时刻抉择（按位置区分）、休赛期连锁事件，社媒类事件按年代过滤
- **经济与商店**：薪水/奖金/签字费入账，球员商店（属性强化、生活小件、团队互动），资金联动事件
- **交易与自由市场**：请求交易、休赛期转会、自由市场签约、裁员与再签约
- **奖项平衡**：MVP / DPOY / 得分王 / 篮板王 / 助攻王 / 最佳阵容 / 全明星，按位置、年代、年龄动态平衡
- **存档系统**：本地 localStorage 自动存档，读档直接继续新赛季
- **主题皮肤**：现代混搭 + 1984 / 1996 / 2003 四时代配色自动演化，Oswald 转播字体

## 🚀 快速开始

纯前端项目，无需构建、无需安装依赖：

1. 直接双击打开 `index.html`（或 `__ai_app.html`）即可游玩；
2. 或启动本地静态服务器（自动打开浏览器）：

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```

浏览器访问 `http://localhost:8765`。

## 🎮 玩法流程

1. **创建球员**：选择位置 → 老虎机夺取属性 → 编辑昵称 → 揭晓 OVR
2. **选秀与加盟**：选秀夜故事线 → 合同签约 → 新秀赛季
3. **赛季循环**：训练营加点 → 82 场常规赛 → 附加赛 / 季后赛 → 奖项 → 休赛期（选秀、交易、自由市场、事件）→ 下一赛季
4. **生涯终章**：退役特刊、生涯海报、历史档位、球员档案库

| 路径 | 说明 |
|---|---|
| `index.html` | 入口壳（ColorboxAI 运行时） |
| `__ai_app.html` | 游戏主体（样式 + 核心逻辑） |
| `game-config.js` | 模拟/属性/平衡参数 |
| `nba2k-data.js` / `nba2k-schedule.js` / `nba2k-archetypes.js` | 现代名单、赛程、模板 |
| `draft-classes.js` | 2026-2030 届 + 历史 1984-2021 届新秀 |
| `era-*.js` | 历史时代（名单、出生年、经济、赛季锚点、替补池、配置） |
| `historical-players.js` | 历史球员库 |
| `story-events.js` / `post-game-events.js` / `iconic-events.js` / `clutch-events.js` | 事件与关键时刻系统 |
| `economy-core.js` / `contracts.js` / `shop-items.js` | 经济、合同、商店 |
| `copy-data.js` | 长文案数据（庆祝/生涯总结/评价/传记） |
| `player-images.js` | 球员头像 ID 映射 |
| `team-logos.js` | 历史年代队标映射 |
| `assets/` | 头像、队标、假人头像、主题样式 |
| `fonts/` | 游戏字体（Fredoka / Nunito / Oswald） |

## 📚 数据说明

- **现代名单**：NBA2K 风格能力值 + 2026 届真实新秀（真实到 2030 届）
- **历史名单**：1984 / 1996 / 2003 真实球员，能力值按 2K 新秀名单风格逐人校准，年龄按真实出生年
- **工资帽/合同**：1984-2027 真实轨迹（Spotrac / SalarySwish），合同年限与薪水随劳资协议演化
- **头像**：NBA 官方头像资源，缺失球员使用统一占位图
